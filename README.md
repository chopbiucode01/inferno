# inferno

A static website recreated from the supplied Inferno PDF design. Open `index.html` in a browser or serve this folder with any static web server.

The **View artwork** button opens `artwork/index.html`, the finished p5.js sketch. Click the canvas to redraw it. The artwork page includes a link back to the website.

The site uses the three supplied images and font subsets embedded in the source PDF. The artwork page loads p5.js 2.3.4 from jsDelivr.
